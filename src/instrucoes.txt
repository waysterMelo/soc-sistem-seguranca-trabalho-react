## 1. Módulo de Gerenciamento de Usuários

### 1.1. Modelo de Dados: `Usuario`
- **`id`**: `Integer` (PK)
- **`nomeCompleto`**: `String`
- **`email`**: `String` (Único)
- **`senha`**: `String` (Armazenar com hash)
- **`nivelAcesso`**: `String` (Enum: `'ADMINISTRADOR'`, `'USUARIO_PADRAO'`)
- **`status`**: `String` (Enum: `'ATIVO'`, `'INATIVO'`)
- **`empresaId`**: `Integer` (FK para `empresas`, nulo)

### 1.2. Endpoints: `/usuarios`
- **`GET /usuarios`**: Lista paginada de usuários. Aceita query params `page`, `size`, e `search`.
  - **Resposta:** Objeto de paginação `{ content: [], totalPages, totalElements, ... }`.
- **`GET /usuarios/:id`**: Busca um usuário.
- **`POST /usuarios`**: Cria um usuário.
- **`PUT /usuarios/:id`**: Atualiza um usuário.
- **`DELETE /usuarios/:id`**: Deleta um usuário.

## 2. Módulo do Dashboard

### 2.1. Endpoint: Próximos Exames ASO a Vencer
- **Objetivo:** Alimentar o card "Próximos Exames Periódicos (ASO)".
- **Método:** `GET`
- **Endpoint:** `/dashboard/aso/proximos-vencimentos`
- **Params:** `dias` (default 30), `limit` (default 5).
- **Resposta:** Array de objetos `[{ id, funcionarioNome, dataVencimento }]`.

### 2.2. Endpoint: Afastamentos Recentes
- **Objetivo:** Alimentar o card "Afastamentos Recentes".
- **Método:** `GET`
- **Endpoint:** `/dashboard/afastamentos/recentes`
- **Params:** `limit` (default 5).
- **Resposta:** Array de objetos `[{ id, funcionarioNome, motivo, dataInicio, totalDias }]`.

### 2.3. Endpoint: Status de Documentos
- **Objetivo:** Alimentar o card "Vencimento de Documento".
- **Método:** `GET`
- **Endpoint:** `/dashboard/documentos-status`
- **Params:** `limit` (default 3).
- **Resposta:** Array de objetos `[{ id, tipo, responsavel, status, dataVencimento }]`. O `status` pode ser "Válido", "Vencido", "Atenção".

### 2.4. Endpoint: Resumo de Empresas
- **Objetivo:** Alimentar o gráfico de "Empresas".
- **Método:** `GET`
- **Endpoint:** `/dashboard/empresas-summary`
- **Resposta:** Objeto com a contagem de empresas por status.
  ```json
  {
    "ativo": 75,
    "inativo": 15,
    "revisao": 10
  }
  ```

### 2.5. Endpoint: Resumo de ASOs Emitidos
- **Objetivo:** Alimentar o gráfico de "ASOs Emitidos".
- **Método:** `GET`
- **Endpoint:** `/dashboard/asos-emitidos-summary`
- **Params:** `periodo` (Enum: `'daily'`, `'weekly'`, `'monthly'`, `'yearly'`).
- **Resposta:** Objeto com `labels` (array de strings) e `data` (array de números).
  ```json
  {
    "labels": ["Jan", "Fev", "Mar", ...],
    "data": [3, 5, 4, ...]
  }
  ```

### 2.6. Endpoint: Resumo de Riscos
- **Objetivo:** Alimentar o gráfico de "Riscos Emitidos por Grupo".
- **Método:** `GET`
- **Endpoint:** `/dashboard/riscos-summary`
- **Resposta:** Array de objetos, um para cada grupo de risco com seu total.
  ```json
  [
    { "grupo": "Físicos", "total": 2 },
    { "grupo": "Acidentes", "total": 2 },
    { "grupo": "Químicos", "total": 5 }
  ]
  ```
